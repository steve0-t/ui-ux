## Čo zatiaľ chýba

- Ľudské zdroje: rozhovor s pacientom a so zdravotníkom konkrétneho pracoviska.
- Lokálny schválený protokol prípravy a vysvetlenie procesu pri zmene termínu.
- Overenie dostupnosti a presného správania digitálnych riešení po prihlásení.
- Dôkazy o tom, či navrhované kroky a pomenovania pacienti správne chápu.

Chýbajúce informácie nie sú doplnené simulovanými rozhovormi ani vymyslenými štatistikami.
